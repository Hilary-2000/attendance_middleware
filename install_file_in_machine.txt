Install HIKVISION CLOUD UPDATER.

1. Install Global Tools First
npm install -g pm2
npm install -g pm2-windows-startup
npm install sharp // this is used for staff and student file compression from whatever size to 200kb or less

2. Get the project from github
:: Option A — from GitHub (recommended)
git clone https://github.com/yourusername/hikvision-middleware.git
cd hikvision-middleware

:: Option B — from zip
:: just extract the zip and cd into the folder

3. Install Dependencies
npm install

4. Create Fresh Config files
:: Copy the example and fill in real values
copy .env.example .env
:: Then open .env in Notepad and update:
::   TERMINAL_HOST, TERMINAL_PASSWORD, SCHOOL_CODE etc.
notepad .env

5. Start PM2
pm2 start ecosystem.config.cjs
pm2 save

6. Register PM2 to start on boot.
pm2-startup install
pm2 save

:: IMPORTANT — pm2-startup / pm2-windows-startup only resurrects PM2 when
:: someone actually LOGS IN to this Windows account (it works by adding an
:: entry under HKCU\...\Run, which only fires at logon). If the machine
:: reboots and nobody logs in (Windows update, power cut, unattended
:: restart), PM2 stays dead and attendance stops silently until a human
:: notices and logs in. This bit us on 2026-09-08/09 — a ~16.5 hour gap
:: where no attendance synced to the cloud. Do step 6b below as well to
:: close that gap.

6b. Register a TRUE boot-time recovery task (no login required)
:: This runs pm2-resurrect.bat as SYSTEM, 60 seconds after Windows boots,
:: regardless of whether anyone logs in. It restores whatever process
:: list was last saved with `pm2 save` (step 5), same as pm2-startup does,
:: it just doesn't need a human to log in first.
::
:: pm2-resurrect.bat and register-boot-task.ps1 are both in this project
:: folder already. Edit the paths inside them if you're deploying to a
:: different machine/username, then:
::
::   1. Open PowerShell as Administrator (right-click PowerShell ->
::      "Run as administrator", approve the UAC prompt — the window
::      title must read "Administrator: Windows PowerShell").
::   2. Run:
powershell -ExecutionPolicy Bypass -File "register-boot-task.ps1"
::
:: This registers a Scheduled Task named
:: "PM2 Resurrect - Hikvision Attendance (Boot)" that fires at every
:: system startup as SYSTEM. Verify with:
Get-ScheduledTask -TaskName "PM2 Resurrect*"
::
:: To test it without actually rebooting (must also be run elevated):
::   pm2 kill
::   Start-ScheduledTask -TaskName "PM2 Resurrect - Hikvision Attendance (Boot)"
::   pm2 status   (should show processes restored within ~5 seconds)

7. Verify everything is running
pm2 status
pm2 logs

8. Restart PM2
pm2 delete all
pm2 start ecosystem.config.cjs
pm2 save

9. Whenever you edit ecosystem.config.cjs (add/remove/rename a PM2 app)
:: Both the logon-trigger (pm2-startup) and boot-trigger (step 6b) recovery
:: mechanisms replay whatever was last saved — not your latest edits —
:: until you re-save:
pm2 save
