Install HIKVISION CLOUD UPDATER  (native Windows Task Scheduler - no PM2)

The middleware runs as three Windows Scheduled Tasks under the SYSTEM account,
so it starts automatically at boot with NO login required and restarts itself
if it crashes.

===========================================================================
 ONE-LINE INSTALL  (fresh PC)
===========================================================================

1. Open Windows PowerShell / Terminal AS ADMINISTRATOR
   (Start menu -> type "PowerShell" -> right-click -> Run as administrator;
    the title bar must say "Administrator").

2. Paste this single line and press Enter:

   [Net.ServicePointManager]::SecurityProtocol='Tls12'; irm https://raw.githubusercontent.com/Hilary-2000/attendance_middleware/main/setup/bootstrap.ps1 | iex

3. Answer the prompts:
   - install location   (press Enter for  C:\attendance_middleware )
   - Notepad opens on .env  -> fill in TERMINAL_HOST, TERMINAL_PASSWORD,
     SCHOOL_CODE, CLOUD_API_BASE_URL, SYNC_TIMEZONE (Africa/Nairobi),
     then SAVE and CLOSE Notepad to continue.

4. Reboot the PC. Wait ~2 minutes, then in a normal PowerShell:

   cd C:\attendance_middleware
   .\setup\manage.ps1 status

   Expect HikvisionDeviceSync with a running "node" process and
   HikvisionMiddleware with a recent run and LastResult 0x0.

That's it. Nothing else is ever needed.

What the one-liner does:
  - installs Node.js LTS + Git (via winget) if they are missing
  - clones this repo (or pulls, if it is already there)
  - runs "npm install"
  - creates .env and config.js from the *_example files, opens .env for editing
  - runs setup\install-native.ps1, which registers 3 SYSTEM scheduled tasks:

      HikvisionDeviceSync  person + face-photo sync loop (Devicesync.js)
                           starts 30s after boot; 10-min watchdog;
                           auto-restart on crash
      HikvisionMiddleware  posts attendance to the cloud (index.js)
                           every 5 minutes
      HikvisionUpdater     git pull new code daily 09:30, then restart
                           device-sync (updater.js)

===========================================================================
 MANUAL INSTALL  (if the one-liner cannot be used)
===========================================================================

1. Install Node.js LTS and Git for Windows. Confirm they are on PATH:
     node -v
     git --version

2. Get the project:
     git clone https://github.com/Hilary-2000/attendance_middleware.git
     cd attendance_middleware

3. Install dependencies:
     npm install

4. Create the config files (both are git-ignored):
     copy .env_example .env
     copy config_example.js config.js
     notepad .env        :: set the real terminal / school / cloud values

5. Register the tasks - ELEVATED PowerShell:
     cd <folder>
     .\setup\install-native.ps1
   (answer "y" to "Uninstall PM2 now?" if this box previously ran PM2)

6. Reboot, then verify:
     .\setup\manage.ps1 status

===========================================================================
 DAY-TO-DAY MANAGEMENT
===========================================================================

   .\setup\manage.ps1 status                 :: overview + recent log lines
   .\setup\manage.ps1 logs device-sync       :: live log (Ctrl+C to quit)
   .\setup\manage.ps1 logs middleware
   .\setup\manage.ps1 logs updater
   .\setup\manage.ps1 restart                :: restart all   (needs admin)
   .\setup\manage.ps1 restart device-sync    :: restart one   (needs admin)
   .\setup\manage.ps1 stop                   :: stop + disable (needs admin)
   .\setup\manage.ps1 start                  :: enable + start (needs admin)

   Raw logs are in  logs\  :
     device-sync-out.log / device-sync-err.log
     middleware-out.log  / middleware-err.log
     updater-out.log     / updater-err.log
   (each rotates to *.log.1 once it passes ~5 MB)

===========================================================================
 UPDATING THE CODE
===========================================================================

   Automatic: HikvisionUpdater runs "git pull" every day at 09:30 and then
   restarts device-sync. The middleware picks up new code on its next
   5-minute run by itself.

   Manual:
     git pull
     .\setup\manage.ps1 restart               (elevated)

   You do NOT need to re-run install-native.ps1 after a code update. Re-run
   it only if you move the project folder or change the task definitions.
   It is safe to run again any time.

===========================================================================
 TROUBLESHOOTING
===========================================================================

   - A task's LastResult is not 0x0  -> open the matching logs\*-err.log.
     The task retries on its next tick.
   - device-sync not running         -> .\setup\manage.ps1 restart device-sync
                                        (elevated), then check its err log.
   - "winget not found" in step 2     -> install Node.js LTS + Git by hand,
                                        then use the MANUAL INSTALL section.
   - Test boot recovery without rebooting (elevated):
       .\setup\manage.ps1 stop
       Start-ScheduledTask -TaskName HikvisionDeviceSync
       Start-ScheduledTask -TaskName HikvisionMiddleware
       .\setup\manage.ps1 status

===========================================================================
 ROLL BACK TO PM2  (not recommended)
===========================================================================

   .\setup\uninstall-native.ps1        (elevated)
   npm install -g pm2
   pm2 start ecosystem.config.cjs
   pm2 save

   ecosystem.config.cjs, pm2-resurrect.bat and register-boot-task.ps1 are
   kept in the repo only for this rollback path.
